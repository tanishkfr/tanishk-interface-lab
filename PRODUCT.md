# LAB/

LAB/ is Tanishk's independent internet playground: interactive experiments, useful creative tools, installable UI components, and a future home for distributed products. It is a place to explore and make things, not a portfolio or SaaS landing page.

The November 2026 V2 brief authorizes independent research, creative direction, implementation, and verification. The user specifically requires spacing, padding, hierarchy, deliberate overlap, and responsive usability to remain fundamental. Do not deploy or replace production without explicit approval.

Preserve all 19 existing component URLs under `/experiments/` and their `/r/` registry endpoints. Component documentation prioritizes usability: live previews, controls, installation, usage, props, accessibility, dependencies, and source.

Launch experiences: Data Matter, Interface Genome, Type Has Mass, Browser Terrarium, The Cost of a Click, Motion Foundry, Vector Kitchen. Controls and exports must actually work. Demonstration data and illustrative simulations must be labeled. No invented product availability or scientific claims. Products may be accurately described as prototypes.

The unreasonable pass adds Sticker City, Almost Nothing, Grid Crimes, and BRUTAL.EXE. Data Matter gains an alternate fossil formation; Interface Genome gains crossbreeding and a functional index layout. Depth and usable controls take priority over adding every proposed concept. Too Much Internet and Impossible Interface remain unexplored directions. The Components section has persistent navigation, searchable gallery/list views, and actual responsive iframe previews while preserving all public APIs and registry endpoints.

Platform: responsive Next.js 16 App Router, React 19, TypeScript. Existing framework and dependency-light architecture are retained. Exploration supports keyboard, touch, reduced motion, and a structured searchable index. Individual projects may have distinct visual worlds. Verification includes rendered desktop, tablet, mobile, deep links, registry installation, exports, error states, build, types, and tests.
