# Changelog

## 0.1.0 — 2026-11-18

First development build. Not published to Figma Community.

### Added

- Six art directions: Brutalist, Swiss Editorial, Radical Minimal, Maximalist, Anti-grid and Controlled Chaos.
- 24 layout grammars with independent spatial logic.
- Seeded procedural planning with bounded candidate generation and quality scoring.
- Chaos, density and hierarchy controls; seed, output ratio, colour/typography preservation and overlap options.
- Selection analysis with role detection and role correction.
- Four native editable Figma variations per batch, placed in a 2×2 container beside the source.
- Real exported thumbnails in the results panel.
- Regenerate, keep/lock, focus, view original and safe batch removal.
- Crossbreed with real DNA interpolation, discrete grammar inheritance, parent compatibility checks and metadata persistence.
- Result-variation thumbnails for cross-batch parent selection on the canvas.
- Missing-font preservation and warnings.
- Dense-composition fallback: editorial index layout for 19–30 elements.
- Batch transaction rollback; only tracked generated nodes are removed.
- Self-contained UI with bundled licensed fonts, light/dark support, reduced-motion support and keyboard navigation.
- 32 automated engine/adapter tests and 9 browser UI QA cases.

### Pending

- Native Figma manual QA.
- Community listing registration and publication.
- Performance measurements on very large real documents.
