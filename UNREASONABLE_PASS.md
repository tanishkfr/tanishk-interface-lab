## Implemented

**Typography:** Gulax from Velvetyne and Apfel Grotezk from Collletttivo. Angular, monolinear short display statements meet a soft, readable grotesk; IBM Plex Mono remains for code and measurements. Original WOFF2 files, explicit weights, local hosting, bundled OFL licenses. The five new font files total approximately 102 KB. Exports embed the actual Apfel faces they use.

**Homepage:** a new working typographic printing press replaces the spiral. Direct dragging, pressure control, keyboard-accessible impression/reset operations and real PNG output. The gallery opens with contrasting loud/quiet experiments and retains an index, search and working category counts across 30 entries. Captions remain outside artwork.

**Components:** persistent grouped navigation, sidebar search, searchable gallery/list views, category and dependency filters, explicit empty state, and the original 19 detail URLs. Each live preview has its own browser viewport, validated same-origin configuration messages, Preview/Configuration tabs, keyboard tab navigation, synchronized settings, bounded controls and intentional internal scrolling. Installation, usage, API, accessibility, dependencies and source remain available. Public component implementations and registry builders are preserved.

**Products:** Vector Kitchen remains accurately labeled a browser prototype. A large violet MORE / COMING / SOON installation lets visitors explore possible future formats without inventing products, downloads or launch dates.

## Audit corrections

The baseline component audit recorded 19 default previews, every control's extreme states, and widths 320, 390, 820, 1440 and 1920. It exposed clipped choice controls, compressed rows and tall content hidden behind fixed stages. Real iframe widths now trigger each demo's responsive behavior, choice controls wrap, long samples scroll, slider labels are explicit and reading/control type is larger.

The final visual pass also corrected the Products button's oversized SVG icon, a gallery gap, an incorrect promoted-card caption, canvas pointer mapping on narrow screens, stale sticker drag coordinates and cancellation, an inherited animated preview width, and low-contrast secondary hero text. Lightweight catalog thumbnails remain rendered; their one canvas engine already observes visibility.
