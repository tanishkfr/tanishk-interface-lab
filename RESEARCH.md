# V2 reference notes

Retrievals and browser captures: `output/lab-v2/research/`. Readable web retrievals, desktop renders, scrolled states, and phone renders were collected separately; a successful navigation is not proof that all media or interactions loaded.

## Decisions grounded in inspection

- [The Pudding](https://pudding.cool/): the rendered collection gives projects independent visual covers while keeping titles and discovery controls legible. LAB uses distinct procedural exhibit covers and a separate direct index. Individual article interactions were not fully studied in this pass.
- [Hoverstat.es](https://www.hoverstat.es/): the browser-window presentation and short editorial captions keep work in focus. LAB keeps navigation outside its artwork and gives captions their own protected space. The showcased third-party iframe loaded only partially.
- [Rauno / Craft](https://rauno.me/craft): the rendered collection uses different scales and media presentations. Some media remained blurred/loading, so detailed motion behavior is not claimed as inspected. LAB borrows the discipline of distinct exhibit scales, not any branded composition.
- [Akaru](https://akaru.fr/): very large condensed lettering and wide bands create architectural scale. LAB uses broad Bricolage lettering as a direct manipulation object while retaining familiar navigation and page scrolling.
- [Maggie Appleton / Garden](https://maggieappleton.com/garden): desktop facets become explicit stacked controls on phone. LAB similarly uses a searchable index and rearranges tool controls for phone width, rather than shrinking the desktop workspace.
- [fffuel](https://www.fffuel.co/) and [rrrepeat](https://www.fffuel.co/rrrepeat/): inspected a real generation instrument and changed a range by keyboard. Geometry, live controls, and an export remain near one another. Vector Kitchen uses its own phyllotactic recipe model and real SVG geometry. The reference's desktop canvas/control layout extended past the captured viewport; LAB explicitly checks viewport overflow.
- [shadcn/ui](https://ui.shadcn.com/) and [installation](https://ui.shadcn.com/docs/installation): readable wayfinding, concrete installation paths, and calm documentation. The original component previews, props, accessibility notes, source sections, and registry delivery remain preserved. The registry was independently tested through the real CLI in a clean consumer.
- [React Bits](https://reactbits.dev/): the rendered page combines actual visual output with implementation context. LAB retains technical context in component documentation and keeps larger experiences on separate routes.
- [lyra.horse](https://lyra.horse/) and [CSS Clicker](https://lyra.horse/css-clicker/): inspected the handmade index and the game's introductory screen. The full game was not played. The useful lesson is permission to make a self-contained browser object for its own sake; Browser Terrarium follows that principle with original creatures and mechanics.
- [Patatap](https://patatap.com/): keyboard A produced a visible geometric event in the captured scene. LAB gives keyboard input a real creative role in its wordmark and type installation. Audio quality was not assessed.
- [Bruno Simon](https://bruno-simon.com/): only an early/loading scene rendered during the capture window. No claim is made about having inspected the driving experience.

## Access limitations

[Neal.fun](https://neal.fun/) and [Codrops Hub](https://tympanus.net/codrops/hub/) returned bot/security checks in the local rendered browser. Web retrievals could expose some text but do not establish rendered interaction research. [Studio Namma](https://studionamma.com/) was visually blank in the initial capture window; its fluid transitions were not observed. These remain research gaps, not completed inspiration studies.

## Type sources and licenses

Original font files come from the official [Google Fonts repository](https://github.com/google/fonts): Bricolage Grotesque (`ofl/bricolagegrotesque`), Instrument Sans (`ofl/instrumentsans`), and IBM Plex Mono (`ofl/ibmplexmono`). The original variable files replaced the static weights returned by the font CSS endpoint during the first attempt. OFL text is included alongside each self-hosted font. No new runtime dependency was required.

## Essay evidence

The essay illustrates mechanisms, without assigning causal effects or presenting session timings as research. Further reading links were verified: [FTC, Bringing Dark Patterns to Light](https://www.ftc.gov/reports/bringing-dark-patterns-light), [Deceptive Patterns taxonomy](https://www.deceptive.design/types), and [W3C, Understanding Interruptions](https://www.w3.org/WAI/WCAG22/Understanding/interruptions.html).
