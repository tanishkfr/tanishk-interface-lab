Current LAB typography

- Gulax by Morgan Gilbert, Velvetyne Type Foundry. Original WOFF2 from https://gitlab.com/velvetyne/Gulax. See gulax-OFL.txt.
- Apfel Grotezk by Luigi Gorlero, Collletttivo. Original Regular, Mittel, Fett and Satt WOFF2 files from https://github.com/collletttivo/apfel-grotezk. See apfel-OFL.txt.
- IBM Plex Mono from the official Google Fonts repository; see the accompanying existing OFL file.

Font files have not been modified. The site assigns CSS family aliases through next/font/local. Gulax uses its original regular weight. Apfel weights are explicitly mapped to 400, 500, 700 and 900. Artwork exports embed Apfel Satt; Grid Crimes embeds the three faces it uses.
